\# API advanced



Python functions that query the Reddit API.



\- `0-subs.py` - returns the number of subscribers of a subreddit

\- `1-top\_ten.py` - prints the titles of the first 10 hot posts of a subreddit

\- `2-recurse.py` - recursively returns the titles of all hot articles of a subreddit

\- `3-count.py` - recursively counts given keywords in the titles of hot articles
